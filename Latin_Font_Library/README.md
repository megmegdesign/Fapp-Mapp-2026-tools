# 欧文フォント見本帳

`index.html`を開くか、おすすめフォントの「欧文フォント一覧」から利用します。GitHub Pagesのサブディレクトリでも動作する相対パス構成です。

- 既存の44元カードを42項目にまとめた一覧・分類・推薦者・説明・リンクを保持。
- サンプル文字、24〜100px、検索、分類、カード／コンパクト、版・スタイル選択、お気に入り、JSON結果保存が利用できます。
- Amiri、Lato、Montserrat、Quicksand、RobotoはGoogle FontsのRegularを優先。スタイル選択から既存のローカル版も選べます。
- その他はFontFaceの`local()`で明示したフォント名を参照。フォントのインストール・有効化・ブラウザ設定によって表示結果は異なります。
- 読み込み失敗時は見本文字をグレーにし、読み込めた代替フォント名（Times New Roman／Arialなど）を明記。候補が利用できない環境ではブラウザ標準書体と表示。実書体としての比較には使えません。Google Fontsの別書体への代替候補は情報のみで、自動で置き換えません。
- Google Fontsはオンライン接続が必要。お気に入りはブラウザのlocalStorageに保存し、Drive版から自動移行しません。

## データと更新

元資料は `../Recommended_fonts/Recommended_fonts.html`。`font-data.js`は既存Drive版からフォント名・説明などのメタデータだけを移植し、個人の絶対パスを相対パスに変更しました。フォント本体は含みません。

元資料更新時は公開版のデータにも反映してください。Drive版の更新スクリプトはローカル専用のため同梱していません。再取り込み時は42項目のIDと既存内容を維持し、絶対パスを含めず、Google Fonts対象が増えた場合は`app.js`の`googleFamilies`も更新します。

旧Drive版はそのまま保存しています。公開版から個人用設定やDrive上のパスは読み込みません。

## フォント本体の管理

フォント拡張子とfonts/を.gitignoreで除外。元から追跡されていた未使用Open Rundeの4ファイルは外部退避済みで、今回の変更で削除対象です。削除を含めてコミットしてください。過去のGit履歴にあるフォントは履歴改変を行っていないため残ります。

Google Fontsの読み込みは[公式CSS API](https://developers.google.com/fonts/docs/css2)に従います。
