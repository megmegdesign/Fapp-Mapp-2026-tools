プロファイル警告と処理方法

プロファイル警告で画像のカラーモードを判別

「プロファイル警告」が表示された際、RGBカラーの画像とCMYKカラーの画像では、選択肢が異なります。まずは警告ダイアログの表示をチェックして、開こうとしている画像のカラーモードがRGBなのかCMYKなのかを判別します。

  • 「プロファイルの不一致」
    • 「○○○の作業用スペースに一致しない」の○○○が画像のカラーモード
  • 「プロファイルなし」
    • 「□□□プロファイルが埋め込まれていません」の□□□が画像のカラーモード

カラーモードを確認できたら、RGB／CMYKそれぞれに応じた処理方法を指定します。

RGBカラー画像

プロファイルあり

基本は「作業用スペースの代わりに埋め込みプロファイルを使用」を選び、埋め込まれたプロファイルを保持して開きます。画像が作成・保存されたときの色の意味を保ったまま開くことができます。

必要に応じて「作業用スペースに変換」を選択して開くこともできます。見た目をできるだけ維持しながら、カラー値を作業用スペースに合わせて変換します。

主にsRGBプロファイルの画像を素材として開き、Adobe RGBの作業用スペースで編集する場合に選択します。

プロファイルなし

「そのままにする」または「作業用RGBを指定」を選択し、Photoshopの現在の作業用スペースを割り当てて開きます。

保存時のプロファイルと異なるプロファイルを割り当てて画像を開くため、保存時とは異なる色で画像が開かれる可能性が高いです。

開いた後、プロファイルを推測して割り当てる

プロファイルが埋め込まれていないRGBデータを本来のカラーで開くには、画像を保存した時に割り当てられていたカラープロファイルを推測して割り当てる必要があります。

「編集」メニュー →「プロファイルの割り当て」でカラープロファイルを割り当て、画像が最も自然に見える状態になるように設定します。

ただし、それが正しい選択かどうかは画像の作者以外には分かりません。可能であれば、作者に確認することをおすすめします。

CMYKカラー画像

元のカラー値を維持して開きます。CMYK画像では、印刷工程でCMYKの数値が重要です。

別のCMYKプロファイルへ変換すると、見た目を近づけられても、元のCMYKのカラーバランスとは異なります。画面上では近い色に見えても、印刷結果では異なる色になることがあります。

プロファイルあり（「プロファイルの不一致」）

「埋め込みプロファイルを使用」を選択します。

元のカラー値を維持するため、「作業用スペースに変換」は選択しないでください。

プロファイルなし

「そのままにする」を選択して開きます。プロファイルが埋め込まれていないCMYK画像についても、元のカラー値を維持します。

開いた後に「プロファイルの指定」は行いません。

入稿準備

  • アンシャープマスク設定目安（350ppi）: 量：〜130〜150〜、半径：〜1.3〜、閾値：6以上

レタッチTips

  • 教科書: Photoshop_Retouch.pdf
  • 明暗別補正
    • シャドウ: RGBサムネイルを Cmd+クリック → RGBサムネイルを Cmd+Shift+クリック（数回） → Cmd+Shift+I で選択範囲を反転 → トーンカーブ調整レイヤーを乗せる
    • ハイライト: RGBサムネイルを Cmd+クリック → RGBサムネイルを Cmd+Option+Shift+クリック（数回） → 選択範囲を反転せず、トーンカーブ調整レイヤーを乗せる
    • 中間調: RGBサムネイルを Cmd+クリック → 少し間を置いてからRGBサムネイルを Cmd+Option+クリック → 警告ダイアログで「OK」 → トーンカーブ調整レイヤーを乗せる
  • 線画抽出
    • ニュートラルフィルター、JPGノイズ削除 → グレースケール → レベル補正でノイズ調整 → グレーサムネイルを Cmd+クリック → Cmd+Shift+クリック（数回） → Cmd+Shift+I で選択範囲を反転 → 別レイヤーを作成し、Option+Delete で描画色で塗りつぶす
  • 切り抜いた縁に残った背景の色（フリンジ）を消す方法

    1. コンテキストタスクバー「被写体を選択」→「マスク」

      対象物を選択し、マスクをかけて背景を非表示に。

      背景の色が対象物に反射している場合、切り抜いたあともふちに背景の色が残ることがある。

    2. 新規レイヤーを作成

    3. 作ったレイヤーにレイヤーメニューから「クリッピングマスクを作成」

      新規レイヤーを人物のレイヤーにクリッピングして、人物の範囲だけに編集が適用される状態にする。

    4. 作ったレイヤーを「通常」→「カラー」に設定

    5. ブラシツールで周辺の色を拾いながら塗る

      修正したい部分のすぐ近くにある本来の色を色を指定（Option＋クリック）で拾い、その色で背景の色が残っている部分を塗る。

      大きめの柔らかいブラシを使い、ふちに沿って自然になじませていく。

画像を生成｜構図とスタイルの参照

コンポジション参照：手描き、フォント、3D画像などを使い、ポーズや構図を誘導。スタイル参照：雰囲気や見た目を誘導。

  1. 「画像を生成」の参照画像で「スタイル」または「コンポジション」を選ぶ。
  2. 参照画像を指定し、生成したい内容を入力して生成する。

制作例：スタイルに水滴の画像、コンポジションにフォント文字を参照し、水滴のような透明の文字を目指す。

※参照方法や併用可否は使用中の画面で確認してください。参照画像そのものを正確に再現する機能ではありません。

プロンプトで編集｜ブラシマークアップ

「プロンプトで編集（Prompt to Edit）」でGeminiモデルを選び、コンテキストタスクバーのマークアップのブラシで形やライン、配置を描く。文字の指示も組み合わせられる。

  1. 編集するピクセルレイヤーまたは生成レイヤーを選択する。
  2. Geminiモデルを選び、ブラシで生成する形や位置を指定する。
  3. プロンプトを入力して生成し、元画像と比較する。
プロンプト例
  • タイポグラフィを白いリボンの形状のように綺麗に繋げる
  • ゴールドの音符と楽譜
  • バラと葉っぱ
  • ドリンクの周りに飛び散る液体のキャラメルと生クリーム
  • バットのスイングの光の軌道
  • テニスボールの残像
  • クーラーから出てくる青く冷たい風
  • 可愛いポップな線と星やハートの装飾の落書き
  • 女性の周りにポップでカラフルな風のイラスト
  • 白い石鹸の泡

石鹸の泡は、泡を置くエリアをブラシで描画して指定する。

生成アップスケール

劣化した画像を改善する候補はTopaz Gigapixel（元画像の特徴を保つ方向）とTopaz Bloom（創造的な細部の補完を許容する方向）。Firefly Upscalerも元画像の特徴を保ちながら拡大・細部改善を行う。

提供メモではFireflyは元からある程度きれいな画像の拡大に向き、劣化画像の復元ではTopazを試す使い分け。生成を繰り返してにじんだ画像の改善にも使う。

※拡大後は小さい文字、ロゴ、商品の細部など、変えてはいけないところを等倍で比較してください。完全な復元は保証されません。

背景を生成｜3つの合成方法

  1. 背景を削除 → 背景を生成 → 調和：被写体を別レイヤーで保持し、背景だけを作る。調和を使う前後は被写体の変化を確認。
  2. プロンプトで背景を生成・編集：被写体と背景をまとめてなじませる用途。被写体が変わっていないか確認。提供メモではFirefly Image 5は元画像に忠実な方向、Nano Banana 2は変更が強くドラマチックな方向という使用感。
  3. 背景を用意 → 切り抜き画像を合成 → 調整：ドリンク正面画像にスプラッシュを追加し、オブジェクト回転で角度を調整、調和で背景になじませる。
プロンプト例
  • スプラッシュを追加

※元画像を別に保持すると比較・修正しやすくなります。調和や生成編集で被写体の外観が完全に保持されるとは限りません。

調和（Harmonize）

被写体を背景になじませる。色、照明、影、トーンを背景に合わせる機能。合成した被写体をピクセルレイヤーにして選び、調和を適用して結果を確認する。スマートオブジェクト・文字・調整レイヤーには直接適用できない。

オブジェクトを回転（Rotate Object）

ピクセルレイヤーやスマートオブジェクトの被写体を選び、「編集 → オブジェクトを回転」などから角度を調整する。

※商品に実在しないディテールが加わる可能性があります。見えない部分を生成させない角度を選ぶ、または必要な角度の実写を用意し、商品画像と照合してください。

実践Tips

Tips｜紙のテクスチャにイラストをなじませる
プロンプト例
  • 白い紙 テクスチャー
  1. 生成した紙の上にイラストを置き、イラストレイヤーを「乗算」にする。
  2. レイヤースタイルの「ブレンド条件」で「下になっているレイヤー」の黒・白のスライダーを動かす。Option（WindowsはAlt）を押しながらハンドルを半分に分離し、中間領域のなじみを調整する。
  3. 最後にイラストレイヤーの不透明度を調整する。
Tips｜コンクリートのひび割れをイラストのマスクに使う
プロンプト例
  • ひび割れたコンクリート
  1. テクスチャ画像に「調整レイヤー → 2階調化」を追加。直下の画像だけにクリッピングして、プロパティで白黒の比率を調整する。
  2. 2階調化レイヤーと画像レイヤーをひとつのスマートオブジェクトにまとめる。
  3. イラストレイヤーに白いレイヤーマスクを設定する。
  4. テクスチャの白黒の見た目をピクセルとしてコピーする。スマートオブジェクト自体をマスクに配置するのではなく、必要に応じて全選択して結合部分をコピーする。
  5. Option（WindowsはAlt）を押しながらイラストのマスクをクリックし、マスク表示へ切り替えてペーストする。

※白は表示、黒は非表示。逆のひび割れ表現にしたい場合はマスクを反転し、位置・大きさを合わせてください。

Tips｜グレー背景で切り抜きや反射色補正を試す
プロンプト例
  • グレーの背景に変更

白飛びしたTシャツなどは、背景をグレーへ変更してから「背景を削除」すると境界を取りやすくなる場合がある。周囲の色が反射した服を切り抜いて使う場合も、グレー背景への生成編集で反射色が補正される場合がある。

※白飛びで失われた情報の正確な復元や反射色補正は保証されません。服の形・色・質感が変わっていないか確認してください。

Tips｜文字・反射・ロゴの合成

画像内の刺繍やネオンなど複雑な文字を変更する。メガネの反射を消す。イメージ画像にテキストやイラストを配置して合成する。

プロンプト例
  • 刺繍の文字を◯◯に変更
  • ネオンの文字を◯◯に変更
  • メガネの反射を消す
  • ロゴの形にリンゴの皮を剥く
  • ロゴの形に編み込み

リンゴ画像＋ロゴ、編み物＋ロゴなど、素材の表現にロゴをなじませる。

Tips｜モックアップを作成

別レイヤーに置いたイラストやデザインを合成する。奥・手前のピントのぼけ、前にある物や人、布のシワにも合わせる表現を試せる。

プロンプト例
  • ラベルデザインを２つの紙コップに合成
  • ポスターに合成
  • 参照のデザインをスカーフに合成

※ロゴや文字が正しい形で残っているか確認してください。

Tips｜まとめて生成して選ぶ

複数の丸を描いてから生成し、異なる円形素材をまとめて作る。バナーやチラシの訴求ポイントを載せるベースなどに使える。

プロンプト例
  • デザインの装飾に使う水滴やジェルの円形素材、ひとつひとつデザインを変える。
Tips｜構図を先に決める

切り抜いたコスメボトルの周りにピンクの丸を配置し、丸の位置に泡を生成する。葉の位置は丸、チェーンはライン、雲はその形を描いて指定する。

プロンプト例
  • ピンクの透明な泡とコスメボトル、背景は淡いピンクの水面
  • 水面に浮かぶCICAの葉とボトル、美しい水面
  • チェーンに縛られた香水瓶
  • 白い綿の雲の上に埋もれた香水瓶、淡いピンクの空
Tips｜構図を保ってスタイルを変える

提供メモではNano Banana 2を推奨。作成したデザインをベースに、変えたい素材と「構図は変えない」を指定する。

プロンプト例
  • ニット生地のデザイン 構図は変えない

ほかに試す素材・表現：クレイアート、クレヨンアート、バルーンアート、ビーズアート、リソグラフ、グリッター、ホログラム、レトロな金属板 エンボス、立体的なクロームメタル シルバーをベースにシアン・紫・ピンクの反射、レース生地 黒背景。

※構図の完全保持や権利上の安全を保証する指示ではありません。生成モデル一覧の注意点を確認してください。

Tips｜春の広告を夏仕様へ編集

手動で作った春用広告デザインに、色味・文字・服装など変更したい要素を指定する。提供メモではNano Banana 2を推奨。

プロンプト例
  • 夏用セールの広告に変更、色味、文字、服装

元デザインがレイヤー分けされている場合は、文字など再生成させたくない要素を非表示にしてから生成し、後で元のレイヤーを戻す方法も使える。
