プロファイル警告と処理方法

プロファイル警告で画像のカラーモードを判別

「プロファイル警告」が表示された際、RGBカラーの画像とCMYKカラーの画像では、選択肢が異なります。まずは警告ダイアログの表示をチェックして、開こうとしている画像のカラーモードがRGBなのかCMYKなのかを判別します。

  • 「プロファイルの不一致」
    • 「○○○の作業用スペースに一致しない」の○○○が画像のカラーモード
  • 「プロファイルなし」
    • 「□□□プロファイルが埋め込まれていません」の□□□が画像のカラーモード

カラーモードを確認できたら、RGB／CMYKそれぞれに応じた処理方法を指定します。

RGBカラー画像

プロファイルあり

基本は「作業用スペースの代わりに埋め込みプロファイルを使用」を選び、埋め込まれたプロファイルを保持して開きます。画像が作成・保存されたときの色の意味を保ったまま開くことができます。

必要に応じて「作業用スペースに変換」を選択して開くこともできます。見た目をできるだけ維持しながら、カラー値を作業用スペースに合わせて変換します。

主にsRGBプロファイルの画像を素材として開き、Adobe RGBの作業用スペースで編集する場合に選択します。

プロファイルなし

「そのままにする」または「作業用RGBを指定」を選択し、Photoshopの現在の作業用スペースを割り当てて開きます。

保存時のプロファイルと異なるプロファイルを割り当てて画像を開くため、保存時とは異なる色で画像が開かれる可能性が高いです。

開いた後、プロファイルを推測して割り当てる

プロファイルが埋め込まれていないRGBデータを本来のカラーで開くには、画像を保存した時に割り当てられていたカラープロファイルを推測して割り当てる必要があります。

「編集」メニュー →「プロファイルの割り当て」でカラープロファイルを割り当て、画像が最も自然に見える状態になるように設定します。

ただし、それが正しい選択かどうかは画像の作者以外には分かりません。可能であれば、作者に確認することをおすすめします。

CMYKカラー画像

元のカラー値を維持して開きます。CMYK画像では、印刷工程でCMYKの数値が重要です。

別のCMYKプロファイルへ変換すると、見た目を近づけられても、元のCMYKのカラーバランスとは異なります。画面上では近い色に見えても、印刷結果では異なる色になることがあります。

プロファイルあり（「プロファイルの不一致」）

「埋め込みプロファイルを使用」を選択します。

元のカラー値を維持するため、「作業用スペースに変換」は選択しないでください。

プロファイルなし

「そのままにする」を選択して開きます。プロファイルが埋め込まれていないCMYK画像についても、元のカラー値を維持します。

開いた後に「プロファイルの指定」は行いません。

レタッチTips

  • 教科書: Photoshop_Retouch.pdf
  • 明暗別補正
    • シャドウ: RGBサムネイルを Cmd+クリック → RGBサムネイルを Cmd+Shift+クリック（数回） → Cmd+Shift+I で選択範囲を反転 → トーンカーブ調整レイヤーを乗せる
    • ハイライト: RGBサムネイルを Cmd+クリック → RGBサムネイルを Cmd+Option+Shift+クリック（数回） → 選択範囲を反転せず、トーンカーブ調整レイヤーを乗せる
    • 中間調: RGBサムネイルを Cmd+クリック → 少し間を置いてからRGBサムネイルを Cmd+Option+クリック → 警告ダイアログで「OK」 → トーンカーブ調整レイヤーを乗せる
  • 線画抽出
    • ニュートラルフィルター、JPGノイズ削除 → グレースケール → レベル補正でノイズ調整 → グレーサムネイルを Cmd+クリック → Cmd+Shift+クリック（数回） → Cmd+Shift+I で選択範囲を反転 → 別レイヤーを作成し、Option+Delete で描画色で塗りつぶす
  • 切り抜いた縁に残った背景の色（フリンジ）を消す方法

    1. コンテキストタスクバー「被写体を選択」→「マスク」

      対象物を選択し、マスクをかけて背景を非表示に。

      背景の色が対象物に反射している場合、切り抜いたあともふちに背景の色が残ることがある。

    2. 新規レイヤーを作成

    3. 作ったレイヤーにレイヤーメニューから「クリッピングマスクを作成」

      新規レイヤーを人物のレイヤーにクリッピングして、人物の範囲だけに編集が適用される状態にする。

    4. 作ったレイヤーを「通常」→「カラー」に設定

    5. ブラシツールで周辺の色を拾いながら塗る

      修正したい部分のすぐ近くにある本来の色を色を指定（Option＋クリック）で拾い、その色で背景の色が残っている部分を塗る。

      大きめの柔らかいブラシを使い、ふちに沿って自然になじませていく。
