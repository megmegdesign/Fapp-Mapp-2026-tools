プロポーショナルフォント

「プロポーショナルフォント」にはフォント名に「P」がついています。

Windows環境には、

  • MS Pゴシック
  • HGPゴシックM
  • BIZ UDPゴシック

などのプロポーショナルフォントが付属しています。

自動カーニング機能のないPowerPointにて重宝します。

ProやStdなどの意味（グリフセット）

「ヒラギノ角ゴPro W3」や「ヒラギノ角ゴStd W8」などのOpenTypeフォントについている「Pro」「Std」は、収録している文字数を表します。

Adobe-Japan1という規格により収録文字が定められています。

同じ「新ゴ」でも、手元に

Std / Pro / Pr5 / Pr6

がある場合には、収録字形数の多い「Pr6」を使います（上位互換性があります）。

モリサワには「Min」「Min2」という独自の文字セットがあります。これらは漢字が少なすぎて、書籍の本文や見出しなどで使えるものではありません。

Nフォント

「ProN」など「N」がついているものは、「JIS2004字形」に準拠したNフォント（「Nつきフォント」）。

168文字が旧字風の字形で表示されます。

※ただし、フォント名に「N」がついていなくても、Nフォントのことがあります。

使う上でのポイント

  • 「Pro」「Pr5」「Pr6」がある場合には、収録文字の多い「Pr6」を使う
  • 特に指定がなければ「Nフォント」を使う

フォントの種類

OpenTypeフォント（OTF）

制作現場における現在の主流。

WindowsとmacOSで互換性があります。

OpenTypeフォントの中にもいくつかの種類があり、同じ書体であっても収録字数や機能が異なります。

TrueTypeフォント

Windowsでよく使われているフォーマットです。

WindowsとmacOSでは互換性がありません。同じフォント名でもドキュメントの体裁が変化します。

OCF／CIDフォント

macOS専用の和文フォントフォーマット。

以前はDTP業界の主流として使われていました。

現在のmacOS・Adobe CCがサポートしているのはCIDフォントのみですが、モリサワ・フォントワークスともにCIDフォントのサポートは終了しています。

Type 1フォント（PostScript Type 1フォント）

1984年にAdobeが発表した欧文用フォントフォーマットで、DTPの黎明期から広く使用されてきました。

Creative CloudでのType 1フォントのサポートは終了しており、2023以降のCreative Cloudでは認識されません。

バリアブルフォント

1つのフォントで太さや字幅などの「デザイン軸」を自由に変更できるフォントです。

従来のフォントと異なり、スタイルを無段階に調整できます。

フォントによって調整できるデザイン軸が異なります。

カラーフォント

文字にカラーが設定されているフォントです。

特定の文字がカラー文字になっているほか、「異体字」パネルからカラー文字を入力できます。

正式には「OpenType-SVGフォント」と呼ばれます。

フォント使用時の注意

サポート終了したType 1フォントを使用したデータ

Type 1フォントを使用して制作し、適切に保存したPDFやIllustratorドキュメントにはフォントデータが埋め込まれています。

データを開かず、保存したままの状態なら、他のデータに配置して使用できます。

例えば、Illustrator 2020で作成した図版データをInDesign 2025で作成したドキュメントに配置した場合、PDF書き出しやプリントアウトを問題なく行えます。

Adobe Fonts、フリーフォントについて

Adobe Fontsやフリーフォントだけでデータ制作を行うには、ウェイトや収録字数が足りません。

さらに、Adobe Fontsはフォントベンダーからの要求などで提供が終了する場合があります。

そのため、フォントを永続的に使用できるとは限りません。
