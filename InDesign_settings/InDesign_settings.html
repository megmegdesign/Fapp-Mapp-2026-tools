最初に変えておきたい設定

  • Creative Cloud 環境設定
    • 以前のバージョンを残す設定に変更。自動更新（アップデート）はオフにしておく。
    • バージョンを新規インストールするときは、「以前のバージョンを削除」を必ずオフにする。
  • 環境設定
    • 高度なテキスト
      • 「選択された文字の異体字を表示」：オフ
      • 「テキスト／テキストフレーム選択で適用可能な異体字属性を表示」：オフ

      どちらもオフにしておくのがおすすめ。これらがオンになっていることで、テキスト編集時の動作がおかしくなるという報告がある。

      • コンポーザー：「Adobe 日本語段落コンポーザー」→「Adobe 日本語単数行コンポーザー」

      デフォルトの「Adobe 日本語段落コンポーザー」から「Adobe 日本語単数行コンポーザー」に変更しておくのがおすすめ。

    • 辞書

      言語「日本語」の設定を変更する。

      • 「二重引用符」：一番上の引用符を選択
      • 「引用符」：一番上の引用符を選択

      デフォルト（一番下）のままだと、俗にいう「まぬけ引用符」が使用される。なお、InDesign 2025からは一番上の引用符がデフォルトになっている。

    • 黒の表示方法
      • 「スクリーン」：すべての黒を正確に表示
      • 「プリント／書き出し」：すべての黒を正確に出力

      それぞれ上記の設定にしておくのがおすすめ。

よく使うショートカット一覧

  • ⌘ + Option + Return：カラー値のいずれかを変更したあとに押すと、他のカラー値も同じ割合で変更される。
    • 例：C100 / M50 / Y60 / K20 の状態でCを50に変更して⌘ + Option + Returnを押すと、50%の比率が適用されM25 / Y30 / K10に変更される。
