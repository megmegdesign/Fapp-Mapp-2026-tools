最初に変えておきたい設定

  • Creative Cloud 環境設定
    • 以前のバージョンを残す設定に変更。自動更新（アップデート）はオフにしておく。
    • バージョンを新規インストールするときは、「以前のバージョンを削除」を必ずオフにする。
  • 環境設定
    • 「バックグラウンドで保存」「バックグラウンドで書き出し」の項目はチェックをオフにする。
    • ブラックのアピアランス
      • スクリーン：すべてのブラックを正確に表示
      • プリント／書き出し：すべてのブラックを正確に出力

よく使うショートカット一覧

  • ⌘ + Option + Return：カラー値のいずれかを変更したあとに押すと、他のカラー値も同じ割合で変更される。
    • 例：C100 / M50 / Y60 / K20 の状態でCを50に変更して⌘ + Option + Returnを押すと、50%の比率が適用されM25 / Y30 / K10に変更される。

生成パターン（Text to Pattern）

プロンプトから繰り返しのベクターパターンを生成。背景、イラスト内の布のパターン、文字の塗りなどに使う。

プロンプト例
  • 花柄、ピンク、春
  1. パターンを適用するオブジェクトの塗りまたは線を選択する。
  2. 「オブジェクト → パターン → パターンを生成」などから生成パネルを開き、プロンプトを入力する。
  3. 密度（Density）を調整し、生成候補から選ぶ。

※元メモの「ND値」は公式の設定名として確認できませんでした。密度を調整する項目は「Density（密度）」として整理しています。

生成塗りつぶし（Generative Shape Fill）

ベクターで作った形に沿って、編集可能なベクターグラフィックを生成する。

Tips｜文字を入れる花のフレーム
  1. 四角の中に楕円を描く。
  2. 楕円部分をくり抜いて、中央に文字を入れる空間がある形を作る。
  3. 形を選択し、生成シェイプ塗りつぶしで花のフレームを生成する。

※生成後も中央の空間や形状が意図どおりか確認してください。

コンセプトからベクター生成（Concept to Vector）

写真やスケッチから、プロンプトで編集可能なベクター表現を生成する。Nano Banana 2の正式表記は「Gemini 3.1（Nano Banana 2）」。写真の一部をイラスト化し、写真とイラストを混ぜる表現に使う。

  1. 写真を選び「コンセプトからベクター」を開く。
  2. パートナーモデルとプロンプトを指定する。ベクターで編集したい場合はラスター出力を選ばない。
  3. 生成候補を確認し、元写真と合成する。
Tips｜洋服・バッグ・サングラスだけイラスト化
プロンプト例
  • 写真の一部の要素をポップなイラストに変換。変換する要素以外は白背景。人物の肌部分も白背景。太い黒線。デフォルメされたポップな表現。白い落書き風ラインや星、キラキラを追加。イラスト化する要素：洋服、バッグ、サングラス。
  1. 生成したベクターを元画像の上に重ねる。
  2. ベクターが編集可能な状態か確認し、必要なパスを選択する。
  3. シェイプ形成ツールでOption（WindowsはAlt）を押しながら不要な部分を削除する。

※ラスター出力のままではシェイプ形成ツールでパスを削除できません。白背景や肌部分が独立した形になっているか確認してください。

Tips｜人物の写真＋線画の背景
プロンプト例
  • モノクロの落書き風の線画。人物は消す。
  1. 元写真から、人物のいない線画の背景を生成する。
  2. 写真の「背景を削除」で人物を切り抜く。
  3. 切り抜いた人物をイラスト背景の上に置く。

ターンテーブル（Turntable）

ベクターアートワークから回転したビューを生成し、別の角度の構図を探索する。編集可能なベクターとして角度展開できる。

※実物の正確な形状や見えない部分の再現を保証する機能ではありません。生成された角度ごとの形・細部を確認してください。
